# PEP Test - 自动化测试

## 🎯 职责

使用 Puppeteer MCP 进行自动化浏览器测试。

**核心目标**：
1. 功能测试（交互、事件）
2. UI 测试（布局、样式、还原度）
3. 响应式测试（不同屏幕尺寸）
4. 无障碍测试（键盘导航、ARIA）
5. 性能测试（渲染时间、内存）

---

## 📋 执行流程

### 阶段 0: 环境准备

```markdown
1. 检查 Puppeteer MCP 是否可用
   ❌ 不可用 → 提示配置 mcp.json

2. 检查组件是否可运行
   ❌ 编译错误 → 提示先修复错误

3. 启动开发服务器
   $ npm run dev
```

## 🧠 关键技术点

### 1. Puppeteer MCP 集成

```markdown
配置 mcp.json:

{
  "mcpServers": {
    "puppeteer": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-puppeteer"]
    }
  }
}

在 Cursor Command 中调用:

使用可用的 Puppeteer MCP 工具:
• puppeteer_navigate - 导航到页面
• puppeteer_screenshot - 截图
• puppeteer_click - 点击元素
• puppeteer_fill - 填充表单
• puppeteer_evaluate - 执行 JS
• puppeteer_pdf - 生成 PDF
```

### 2. 测试用例生成

```typescript
function generateTestCases(component: Component, spec: Spec): TestCase[] {
  const cases: TestCase[] = [];
  
  // 根据 Props 生成交互测试
  for (const prop of component.props) {
    if (prop.type === 'function') {
      cases.push({
        type: 'event',
        name: `${prop.name} 事件触发`,
        action: () => triggerEvent(prop.name),
        expect: () => eventFired(prop.name),
      });
    }
  }
  
  // 根据 spec 生成功能测试
  for (const feature of spec.features) {
    cases.push({
      type: 'functional',
      name: feature.title,
      steps: feature.acceptance_criteria.map(toTestStep),
    });
  }
  
  return cases;
}
```

### 3. UI 对比算法

```typescript
async function compareUI(designPath: string, actualPath: string): Promise<CompareResult> {
  const design = await loadImage(designPath);
  const actual = await loadImage(actualPath);
  
  // 像素级对比
  const diff = pixelmatch(design, actual, null, width, height, {
    threshold: 0.1,
  });
  
  const similarity = (1 - diff / (width * height)) * 100;
  
  return {
    similarity,
    differences: findDifferences(design, actual),
  };
}
```

## 🔧 执行指南

### 作为 AI，您需要：

1. **调用 Puppeteer MCP 工具**
   - 启动浏览器
   - 导航到组件页面
   - 执行测试用例

2. **生成测试用例**
   - 根据 spec.md
   - 根据 features.json
   - 覆盖所有验收标准

3. **执行测试并记录结果**
   - 每个用例的通过/失败
   - 截图和视频（如需要）
   - 性能指标

4. **生成测试报告**
   - HTML 格式
   - 包含截图和指标
   - 提供改进建议

---

## ⚠️  注意事项

1. **Puppeteer MCP 需要配置**
   - 确保 mcp.json 正确配置
   - 首次使用需要安装依赖

2. **开发服务器需要运行**
   - 测试前启动 dev server
   - 确保组件可访问

3. **测试可能较慢**
   - 完整测试需要 5-8 分钟
   - 提示用户耐心等待

4. **生成有价值的报告**
   - 不仅是通过/失败
   - 提供具体的改进建议
