## 🧠 关键技术点

### 1. 归档文件命名规范

```markdown
格式: {日期}_{任务ID}_{任务标题}.md

示例:
• 2025-12-18_FEAT-003_实现轮播逻辑.md
• 2025-12-18_UI-001_实现基础样式.md

优势:
• 按日期排序
• 任务 ID 可追溯
• 标题可读性高
```

### 2. Git Commit 信息规范

```markdown
格式: {type}({scope}): {subject}

{body}

Ref: {task-id}

类型 (type):
• feat: 新功能
• fix: 修复
• refactor: 重构
• style: 样式调整
• test: 测试
• docs: 文档
• chore: 杂项

范围 (scope):
• 组件名称（如 pep-common-banner）

主题 (subject):
• 简短描述（50 字符内）

正文 (body):
• 详细描述（可选）
• 使用 - 列表

引用 (Ref):
• 关联的任务 ID
```

### 3. 智能提交信息生成

```typescript
function generateCommitMessage(task: Feature, changes: FileChange[]): string {
  const type = inferCommitType(task.category);
  const scope = task.component;
  const subject = task.title;
  
  const body = [
    ...task.acceptance_criteria.map(c => `- ${c}`),
    ...extractKeyPoints(task.description),
  ].join('\n');
  
  return `${type}(${scope}): ${subject}

${body}

Ref: ${task.id}`;
}

function inferCommitType(category: string): string {
  const mapping = {
    'feature': 'feat',
    'ui': 'style',
    'testing': 'test',
    'docs': 'docs',
    'optimization': 'refactor',
    'setup': 'chore',
  };
  return mapping[category] || 'feat';
}
```
