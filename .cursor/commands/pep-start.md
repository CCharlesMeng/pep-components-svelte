# PEP Start - 组件初始化

## 🎯 职责

初始化一个新的 PEP 组件，生成可运行的组件骨架和初始 spec.md。

**核心目标**：
1. 快速生成可运行的组件骨架
2. 通过智能对话理解需求（可选）
3. 生成初始 `spec.md`
4. 为后续开发打好基础

**下一步**：运行 `/pep-spec` 完善需求规格

---


## 🎯 关键设计原则

### 1. 对话式交互
- 所有选择通过对话完成（A/B 选项）
- 支持自然语言输入（智能识别意图）
- 允许用户跳过（'skip' 快速生成）

### 2. 智能推断优先
- 根据用户描述推断组件结构
- 展示推断结果并请求确认
- 不过度询问细节（留待 /pep-spec）

### 3. 灵活性
- 支持三种模式（标准模板 / 组件拷贝 / AI 生成）
- 用户可在流程中切换选择
- 支持中途退出

### 4. 引导性
- 明确标注推荐选项
- 提供使用场景说明
- 清晰的下一步指引

### 组件名称转换

```javascript
// kebab-case to PascalCase
function toPascalCase(kebabCase) {
  return kebabCase
    .split('-')
    .map(word => word.charAt(0).toUpperCase() + word.slice(1))
    .join('');
}

// 示例
'pep-button' → 'PepButton'
'pep-common-banner-v2' → 'PepCommonBannerV2'
```
