## 核心功能

## Props 设计

| Prop        | 类型   | 默认值                | 说明         |
| ----------- | ------ | --------------------- | ------------ |
| className   | string | ''                    | 自定义类名   |
| title       | string | '组件标题'            | 卡片标题     |
| description | string | '这是一个示例组件...' | 卡片描述文本 |
| buttonText  | string | '点击增加'            | 按钮文本     |

## 插槽设计

| 插槽名  | 说明                           |
| ------- | ------------------------------ |
| default | 自定义内容区域，显示在卡片底部 |

## 样式要求

### 卡片样式

- 白色背景，圆角 8px
- 边框颜色 #e5e7eb
- 悬停时阴影加深
- 最大宽度 400px，居中显示

### 响应式设计

- 移动端（< 640px）调整内边距和字体大小
- 保持良好的视觉层次

### 颜色规范

- 主色：#3b82f6（蓝色）
- 文本主色：#191919
- 文本次要色：#6b7280
- 背景色：#f9fafb
