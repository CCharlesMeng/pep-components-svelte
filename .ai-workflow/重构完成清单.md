```python
def generate(self):
    # 1. 拷贝模板目录
    shutil.copytree(TEMPLATE_DIR, self.component_dir)
    
    # 2. 替换占位符
    self._replace_placeholders_in_directory()
    
    # 3. 重命名文件
    self._rename_placeholder_files()
    
    # 4. 可选增强
    if self.mode == 'custom':
        self._apply_custom_enhancements()
```

## 🎯 核心改进

### Before（代码生成）❌

```python
def _template_minimal_component(self) -> str:
    return f"""<script lang="ts">
  export let items = [];
</script>
...
"""
```

**问题**：
- 可能有语法错误
- 配置不完整
- 依赖不一致
- 无法保证可运行

### After（模板拷贝）✅

```
templates/component/         # 稳定的模板
    ↓ 拷贝
components/pep-new/          # 新组件
    ↓ 替换占位符
100% 可运行的组件 ✅
```

**优势**：
- ✅ 保证能运行（模板本身就能运行）
- ✅ 配置完整（所有文件都有）
- ✅ 依赖一致（与现有组件一致）
- ✅ 易于维护（更新模板即可）

## 📝 占位符系统

| 占位符 | 说明 | 示例 |
|--------|------|------|
| `{{COMPONENT_NAME}}` | 组件名称（kebab-case）| `pep-my-component` |
| `{{COMPONENT_NAME_PASCAL}}` | 组件名称（PascalCase）| `PepMyComponent` |
| `{{DESCRIPTION}}` | 组件描述 | "我的组件" |
| `{{INIT_DATE}}` | 初始化时间 | `2025-12-18T10:30:00Z` |

**使用示例**：

模板：
```json
{
  "name": "{{COMPONENT_NAME}}",
  "description": "{{DESCRIPTION}}"
}
```

生成后：
```json
{
  "name": "pep-my-component",
  "description": "我的组件"
}
```
