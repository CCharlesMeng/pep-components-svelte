# 首次使用：快速配置指南

本指南帮助您在5分钟内完成Cursor自主编码流程的首次配置。

---

## 📋 前置要求

- ✅ macOS/Linux/Windows
- ✅ Python 3.8+
- ✅ Git已配置
- ✅ Cursor IDE
- ✅ pnpm（如果是monorepo项目）

---

## 🚀 快速配置（3步）

### 第1步：克隆或下载工具

```bash
# 方案A: 克隆到项目根目录（推荐）
cd /path/to/your/project
git clone https://github.com/your-org/cursor-autonomous-coding.git

# 方案B: 克隆到其他位置
git clone https://github.com/your-org/cursor-autonomous-coding.git ~/cursor-tools
```

### 第2步：检查 Python 版本

```bash
# 检查 Python 版本（需要 3.8+）
python3 --version

# 输出示例: Python 3.11.0
```

**✅ 无需安装依赖！**

所有脚本**仅使用 Python 标准库**，无需安装任何外部依赖包。Python 3.8+ 自带的标准库已经足够。

**可选增强**（非必需）:

如果你想要更美观的终端输出（可选），可以安装：

```bash
# 可选：更美观的终端输出
pip3 install --user rich

# 可选：使用虚拟环境
python3 -m venv .venv
source .venv/bin/activate
pip3 install rich
```

**依赖说明**:
- ✅ **核心功能**: 零依赖，仅用 Python 3.8+ 标准库
- 🎨 **可选增强**: rich（更美观的终端输出，非必需）

### 第3步：验证可用性

```bash
cd cursor-autonomous-coding

# 查看帮助信息
python3 scripts/next_task.py --help

# 输出示例：
# usage: next_task.py [-h] [--component COMPONENT] ...
# 
# 如果能看到帮助信息，说明可以正常使用！✅
```

**测试脚本**:
```bash
# 测试各个脚本是否可用
python3 scripts/next_task.py --help
python3 scripts/mark_done.py --help
python3 scripts/report.py --help
python3 scripts/validate.py --help

# 全部能显示帮助信息即为成功！✅
```

## 🎯 首次使用：两种场景

### 场景A：Monorepo项目（100+组件）

**适用于**: pnpm workspace、多组件项目

```bash
# 1. 进入monorepo根目录
cd /path/to/pep-components-svelte

# 2. 初始化第一个组件
python3 cursor-autonomous-coding/scripts/init_component.py \
  --component pep-common-banner

# 3. 查看生成的文件
ls components/pep-common-banner/
# 输出: features.json  DEVELOPMENT.md  .component-dev/

# 4. 获取第一个开发任务
python3 cursor-autonomous-coding/scripts/next_task.py \
  --component pep-common-banner \
  --save

# 5. 复制输出的提示词，在Cursor中开始开发！
```

**下一步**: 查看 [02-单组件开发.md](./02-单组件开发.md)

### 场景B：标准项目

**适用于**: 单体应用、中小型项目

```bash
# 1. 准备项目规格文档
cat > spec.md << 'EOF'
# 我的项目
## 目标
构建一个待办事项管理应用
## 核心功能
- 添加/删除待办事项
- 标记完成状态
- 数据持久化
EOF

# 2. 初始化项目
python3 cursor-autonomous-coding/scripts/init_project.py --spec spec.md

# 3. 获取第一个任务
python3 cursor-autonomous-coding/scripts/next_task.py --save

# 4. 开始开发！
```

## 🔧 可选配置

### 配置全局规则（Monorepo）

如果您的monorepo有统一的组件规范（命名、文档、测试等），可以配置全局规则：

```bash
# 1. 编辑全局规则
vim cursor-autonomous-coding/global-rules.json

# 2. 验证所有组件是否符合规则
python3 cursor-autonomous-coding/scripts/validate_global_rules.py --all

# 3. 自动修复简单问题
python3 cursor-autonomous-coding/scripts/validate_global_rules.py --all --fix
```

**示例规则**:
```json
{
  "naming": {
    "component_prefix": "pep-",
    "file_naming": "kebab-case"
  },
  "required_files": [
    "README.md",
    "package.json",
    "features.json"
  ]
}
```

### 启用全自动化模式（可选）

如果您希望自动循环开发任务（类似Claude SDK），可以启用自动化模式：

```bash
# 自动化开发：获取任务 → 等待开发 → 测试 → 提交 → 下一个
python3 cursor-autonomous-coding/scripts/auto_develop.py \
  --component pep-common-banner \
  --max-iterations 5
```

**适用场景**:
- ✅ 专注开发，减少手动命令
- ✅ 批量处理多个小任务
- ⚠️ 需要人工审查时不推荐

## 📝 生成的文件说明

### Monorepo模式

初始化组件后会生成：

```
components/pep-common-banner/
├── features.json           # 功能清单（JSON格式）
├── DEVELOPMENT.md          # 开发日志
└── .component-dev/         # 会话状态目录
    ├── current_prompt.md   # 当前任务提示词
    └── session_state.json  # 会话状态
```

### 标准项目模式

初始化项目后会生成：

```
your-project/
├── features.json           # 功能清单
├── DEVELOPMENT.md          # 开发日志
└── .cursor-dev/            # 会话状态
```

## 🎓 核心工作流程

```
1. 获取任务
   └─> python3 scripts/next_task.py --component xxx --save

2. 复制提示词到Cursor
   └─> 在Cursor中粘贴，开始AI辅助开发

3. 开发完成
   └─> 测试、验证功能

4. 标记完成
   └─> python3 scripts/mark_done.py --feature-id 1

5. 提交代码
   └─> git add . && git commit -m "feat: ..."

6. 查看进度
   └─> python3 scripts/report.py --component xxx

7. 重复步骤1
```

## ❓ 常见问题

### Q1: 需要安装依赖吗？

**答案**: ❌ **不需要！**

所有脚本仅使用 Python 3.8+ 标准库，无需安装任何外部依赖。

```bash
# 只需要检查 Python 版本
python3 --version  # 需要 3.8+

# 然后就可以直接使用
python3 scripts/next_task.py --help
```

**可选增强**: 如果想要更美观的终端输出，可以安装 `rich` 包（非必需）

### Q2: 工具放在哪里？

**推荐**: 放在项目根目录
```
your-project/
├── cursor-autonomous-coding/  ← 工具目录
├── components/                ← 你的代码
└── package.json
```

**原因**: 路径简单，命令统一

### Q3: features.json 从哪来？

**方案1**: 手动编写（推荐）
```bash
vim components/pep-button/features.json
```

**方案2**: 从spec.md自动生成
```bash
python3 scripts/init_component.py \
  --component pep-button \
  --spec components/pep-button/spec.md
```

### Q4: 多人协作怎么办？

每个人负责不同的组件：

```bash
# 张三负责 pep-button
git checkout -b feature/pep-button
python3 scripts/next_task.py --component pep-button

# 李四负责 pep-modal
git checkout -b feature/pep-modal
python3 scripts/next_task.py --component pep-modal
```

### Q5: 如何只看Cursor AI的核心用法？

最简单的用法只需要2个命令：

```bash
# 1. 获取任务提示词
python3 scripts/next_task.py --component xxx --save

# 2. 复制 .component-dev/current_prompt.md 到Cursor
#    然后在Cursor中跟AI对话开发
```
