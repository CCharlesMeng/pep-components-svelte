# 产品优势组件 (pep-product-advantage-v2) 需求文档

## 1. 组件概述
- **名称与用途**：产品优势展示楼层。通过响应式网格展示产品的核心价值点，支持多行排版及移动端手风琴式交互。
- **DOM 路径与规范**：
  - 外层：`PepFloorContainer` (控制背景 `light/grey` 及间距)
  - 头部：`PepTitle` (渲染主副标题)
  - 主体：`.por-section-body` -> `.por-row` (24 栅格容器) -> `.por-col-*`
  - 卡片：`.por-card` (包含图片与内容区)

## 2. 布局要求 (关键)

### 2.1 行级栅格布局 (Row-Level)
支持基于 24 栅格系统的四种行比例：
- **1列 (layout: 1)**：单列占满 24 栅格。
- **2列等宽 (layout: 2)**：12:12 比例。
- **2列非对称 (layout: 3)**：14:10 比例（左宽右窄）。
- **2列非对称 (layout: 4)**：10:14 比例（左窄右宽）。

### 2.2 卡片内部布局 (Card-Level)
这是组件最核心的排版逻辑，支持随屏幕宽度变化的布局倒换：

#### **PC 端 ( >768px )：左右并排模式**
- **容器**：采用 `display: flex; align-items: center;`。
- **左侧内容区 (`.card-content`)**：
  - 纵向排版：卡片标题 -> 描述列表 -> 按钮组。
  - 占据剩余空间 (`flex: 1`)。
- **右侧图片区 (`.card-image`)**：
  - 放置背景图，图片尺寸随所在列宽自适应。
  - 保持固定或比例宽度。

#### **移动端 ( ≤768px )：上下堆叠模式**
- **容器**：转为 `display: flex; flex-direction: column;`。
- **图片区**：移动至**上方**。
- **内容区**：移动至**下方**，且默认进入**折叠逻辑**（见第 3 节）。

## 3. 功能与交互行为
- **移动端折叠逻辑**：
  - **模式**：多选展开（Accordion-style）。
  - **初始态**：第一个卡片内容默认展开，其余折叠。
  - **交互**：点击卡片标题（`.card-title`）区域触发内容区的显隐切换。
  - **动画**：使用 `svelte/transition` 实现高度平滑过渡。
- **图片处理**：支持懒加载，未加载前显示占位色块。
- **多端跳转**：按钮组件需集成链接适配器，处理内外部链接差异。

## 4. 样式与设计规范
### 4.1 响应式断点与 Token
| 断点 | 宽度范围 | 标题字号 | 楼层间距 | 卡片布局 |
| :--- | :--- | :--- | :--- | :--- |
| **L** | >1600px | 28px | 80px | PC (左右) |
| **M** | 1280-1600px | 22px | 60px | PC (左右) |
| **S** | 769-1280px | 18px | 40px | PC (左右) |
| **XS**| ≤768px | 14px | 20px | **移动 (上下 + 折叠)** |

### 4.2 设计细节
- **列表符号**：当 `showLICircle` 为 true 时，描述前显示品牌色圆点。
- **按钮样式**：支持多按钮并排，间距通常为 12px。

## 5. 可配置项 (Props)
| 字段名 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `baseInfo.theme` | `string` | `light` | `light`(白底), `grey`(灰底) |
| `cardItemLists[].layout`| `number`| `2` | 24 栅格比例 (1/2/3/4) |
| `cardItem[].cardTitle` | `string` | - | 卡片标题 |
| `cardItem[].bgImage` | `string` | - | 独立图片 URL |
| `cardItem[].cardInfos` | `array` | - | 描述列表 (支持富文本) |
| `cardItem[].btnLists` | `array` | - | 按钮配置数组 |

## 6. 测试与验收标准
- **UI 还原**：验证 14:10 布局下，左侧文字与右侧图片的空间分配是否准确。
- **交互验证**：在移动端模拟器下，连续点击多个卡片标题，验证“多选展开”是否生效且无闪烁。
- **国际化**：切换 RTL 模式，验证卡片内部的图文顺序是否自动镜像（文字变右，图片变左）。
